### 👋 About Me
Computer Engineering graduate building production-ready systems at the intersection of cross-platform mobile (Flutter) and AI engineering. I've shipped apps, wired RAG pipelines, and survived enough production bugs to develop strong opinions about architecture.

> *"I care deeply about writing clean, maintainable code — mostly because I've had to debug the alternative."*
